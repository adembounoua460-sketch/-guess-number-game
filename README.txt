لعبة خَمّن الرقم — نسخة تطبيق ويب تقدمي (PWA)

الملفات:
- index.html: اللعبة.
- manifest.webmanifest: تعريف التطبيق وأيقونته.
- sw.js: التخزين المؤقت لتشغيل اللعبة دون اتصال بعد أول تحميل ناجح.
- icons/: أيقونات التطبيق.

طريقة التحديث على GitHub:
1. افتح مستودعك الحالي.
2. ارفع واستبدل index.html.
3. أضف manifest.webmanifest و sw.js.
4. أضف مجلد icons وبداخله icon-192.png و icon-512.png.
5. اضغط Commit changes وانتظر اكتمال GitHub Pages.

رابط المشروع يبقى بنفس عنوان GitHub Pages الحالي.
بعد فتح الموقع مرة واحدة مع الإنترنت، افتح Chrome > القائمة ⋮ > تثبيت التطبيق أو إضافة إلى الشاشة الرئيسية.
بعد التثبيت، يفترض أن تفتح اللعبة دون واجهة المتصفح. وضع عدم الاتصال يعمل بعد نجاح أول تحميل وتخزين الملفات.
